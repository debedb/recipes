# recipes

Keto/paleo-leaning recipes. Ingredients and steps. No life story, no stock
photos, no video.

Format: one markdown file per recipe, with frontmatter for diet tags and
whether it has actually been cooked yet. Adaptations - vegetarian, paleo,
kosher, or improvised - are their own file, linked to the parent by
`adapted_from:`. See CLAUDE.md.

Published at https://recipes.debedb.com with schema.org Recipe markup,
so a recipe importer can read a page. `python3 build.py _site` builds it.
